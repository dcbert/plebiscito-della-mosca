# Security

This is a static satire site. There are no accounts, no cookies of ours, and the LIF worker never leaves the browser.

Please **do** report:

- Unexpected network calls
- XSS via pack, session JSON, or the PNG card exporter
- Anything that could be mistaken for a real parliamentary document

Please **do not** report “the fly is biased.” That is the decoder table. It is labelled as arbitrary in Metodi.

Use GitHub private vulnerability reporting, or open an issue if the bug is already public.
